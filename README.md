## Important Note on Images
This repository contains only split indices, label mappings, trained model weights, 
and analysis code. The original herb images are NOT included and are NOT 
redistributed here, because the licensing of the original source is unclear. 
Images were originally compiled and shared by a third party; see the manuscript's 
Data Availability Statement for the original source and details.
# TCM-93class-decoction-benchmark
Split indices, label mapping, model weights, and code for the 93-class TCM decoction-piece image classification benchmark (Symmetry, submitted 2026)
This repository will host the train/validation/test split indices, class label mapping, trained model weights, and analysis code for the manuscript "Image-Based Sensing and Deep Learning for Quality Control of Traditional Chinese Medicine Decoction Pieces: A 93-Class Benchmark Study" (Symmetry, submitted 2026). The train/validation/test split manifests, class label mapping, and trained model checkpoints (see Releases) are available in this repository.
