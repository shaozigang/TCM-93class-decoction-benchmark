# TCM-93class-decoction-benchmark
Split indices, label mapping, model weights, and code for the 93-class TCM decoction-piece image classification benchmark (Symmetry, submitted 2026)
This repository will host the train/validation/test split indices, class label mapping, trained model weights, and analysis code for the manuscript "Image-Based Sensing and Deep Learning for Quality Control of Traditional Chinese Medicine Decoction Pieces: A 93-Class Benchmark Study" (Symmetry, submitted 2026). Contents will be uploaded upon acceptance.
